# Alké Network — Full Website and Member Portal Redesign

## Objective

Redesign **alke.network** and build the frontend for **app.alke.network** around Alké Network’s new strategic direction.

Alké Network is no longer positioned primarily as a DLT adoption network.

It is now:

# **The institutional network for frontier-technology adoption.**

Alké brings African and diaspora institutions together to understand, test, and safely adopt emerging technologies—beginning with **AI and distributed-ledger technology**.

The long-term purpose is to help institutions:

* Understand how frontier technologies are changing their sectors
* Learn from peer institutions
* Develop practical institutional use cases
* Experiment safely before production adoption
* Design and test new products and services
* Establish governance, policy, risk, and compliance readiness
* Build internal technical capability
* Reduce long-term dependency on external technology providers
* Progress toward greater digital and AI sovereignty

The public website should explain and recruit.

The member platform should deliver the actual Alké experience.

> **The website explains Alké. The portal delivers Alké.**

* Modify backend code
